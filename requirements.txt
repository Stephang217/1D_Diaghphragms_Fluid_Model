# Pinned to the environment the reported results were produced in, so Appendix C
# can quote exact versions and mean it. Developed on Python 3.14.7.
#
# Reproducing the headline result needs numpy alone:
#     python3 scripts/reproduce.py
# That script runs one simulation at the protocol point and checks it against the
# reference value. It imports nothing outside numpy on purpose, so a broken
# Jupyter install cannot make a reproduced result look like a failed one.
#
# The fuller route also redraws the figures and reads the cached ensembles, and
# needs jupyter, pandas and matplotlib:
#     jupyter nbconvert --to notebook --execute uq_reproducible_result.ipynb
#
# Regenerating the ensembles needs numpy alone again: scripts/uq_sweep.py and
# src/model.py import nothing else.
#
# Loosen to >= on an older Python. Note that the seeded RNG stream is
# not guaranteed identical across numpy major versions, so a regenerated ensemble
# may differ sample-for-sample while matching statistically. The protocol point
# itself is deterministic and reproduces exactly regardless.
