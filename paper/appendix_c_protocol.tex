\section{Code and data}
\label{app:Appendix C}

Every figure and number in this report comes from one repository,
%
\begin{center}
  \url{https://github.com/Stephang217/1D_Diaghphragms_Fluid_Model}
\end{center}
%
tagged \texttt{submission} at the state these results were produced with
(commit \texttt{<FILL IN AT SUBMISSION>}). Running it needs Python 3.14 and
\texttt{numpy}, with \texttt{pandas} and \texttt{matplotlib} to redraw the
figures. Exact versions are pinned in \texttt{requirements.txt}.

\begin{verbatim}
    git clone https://github.com/Stephang217/1D_Diaghphragms_Fluid_Model
    cd 1D_Diaghphragms_Fluid_Model
    git checkout submission
    pip install -r requirements.txt
\end{verbatim}

Three notebooks carry the work. \texttt{dimensionless\_model.ipynb} holds the
four-group results of Sections \ref{sec:Verification} to
\ref{sec:The fluid fingerprint: compression versus rarefaction},
\texttt{diaphragm\_metafluid.ipynb} the dimensional groundwork behind them, and
\texttt{uq\_reproducible\_result.ipynb} the tolerance ensembles of
Section \ref{sec:Diaphragms that differ from one another}. The simulator itself
lives in \texttt{src/}, shared by the notebooks and by the sweep scripts in
\texttt{scripts/}, so that every number in this report comes from one
implementation rather than several copies of one.

Sweeps taking longer than a few minutes ship as cached CSVs in
\texttt{results/}, each carrying a header that records its seed, lattice
settings, package versions and wall time. A notebook loads the cache when it is
present, so all three run top to bottom in minutes; setting
\texttt{FORCE\_RERUN = True} recomputes from scratch instead.

The simulation is deterministic, with no compiled extensions and no GPU, so a
rerun reproduces the reported numbers to floating-point round-off rather than to
a tolerance. Randomness enters only in the ensembles of
Section \ref{sec:Diaphragms that differ from one another}, where every seed is
recorded in the CSV header. The protocol for reproducing the wave speed of
Section \ref{sec:Diaphragms that differ from one another} from a clean checkout,
together with its reference value and tolerance, is submitted separately.
